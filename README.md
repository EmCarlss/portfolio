# Emanuel Carlsson – academic minimal GitHub Pages portfolio

This is a minimal academic-style GitHub Pages portfolio.

## Structure

- `index.html` – the webpage
- `assets/style.css` – minimal academic styling
- `assets/` – optional folder for screenshots or other files

## Publish on GitHub Pages

1. Create a GitHub repository, for example:
   - `EmCarlss.github.io` for a main personal page
   - or `portfolio` for a project page

2. Upload:
   - `index.html`
   - the complete `assets/` folder

3. Go to:
   Settings → Pages

4. Select:
   Deploy from branch → main → root

5. Save.

## Update before publishing

- Add a direct link to the Shiny app if public.
